# prosperity4
IMC trading challenge 4
Please use the four folders as according to what you are working on:
Final Submissions: Will include each round as a separate file and only the best results file should be kept in it.
Optimisation: These will include separate commodities, baskets, futures and options to trade on and optimise. According to the strategy name make a new file and optimise it for example market making etfs themselves or arbitraging the etfs with the individual commodity ratios
Testing: These are full files (after optimisation files have been combined together)
Tools: Included in this will be the backtester and some data visualisation tools for analysis


Finally leave the files folder for updating the price data needed for the backtest. 
To use the backtester cd into backtest and then run the following piece of code: python3 backtester.py wrapper.py:totest.py
